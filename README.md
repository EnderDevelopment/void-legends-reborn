# Void Legends Reborn Minecraft Modpack Setup Guide

Void Legends Reborn is a Minecraft modpack setup guide for preparing a Crazy Craft 4.0-inspired CurseForge profile for Minecraft 1.7.10 and Forge 10.13.4.1614. It explains how to seek out compatible, authorized versions of the original Legends Mod and OreSpawn, omit recipe-scrambling mods, and export a tested pack. It does not contain a Minecraft mod, mod files, or an updated Legends release.

## Install

1. Install or open the CurseForge app.
2. Create a custom Minecraft 1.7.10 profile using Forge 10.13.4.1614, if that legacy setup is available.
3. Find compatible mod versions through their original developers or authorized download sources. Check each mod’s requirements and terms; do not use unofficial re-uploads.
4. Add the mods to the profile only through installation methods permitted by their authors.

## Use

1. Leave out any recipe-randomizer or recipe-scrambler mod.
2. Test the completed profile locally and resolve any conflicts or dependencies according to the mod authors’ instructions.
3. Use CurseForge’s Export Profile action, then review the archive’s manifest and overrides before sharing or uploading it.
4. Follow the mod authors’ licenses. Do not redistribute mod files unless their licenses permit it.

This repository contains only this setup guide. It does not provide mod jars, Minecraft or Forge binaries, custom mod code, or a CurseForge manifest.
